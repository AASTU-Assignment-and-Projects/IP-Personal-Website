Blind Vision : Assistive Navigation

Blind Vision is a Raspberry Pi-based assistive-navigation prototype for people with visual impairments. It combines ultrasonic sensing with a camera and audio feedback; OpenCV and dlib support known-person recognition, while Tesseract OCR reads printed text aloud. Object detection was a planned extension, not a completed feature. The project helped build my interest in practical, human centred AI.

Leyu : Dynamic Task Allocation

As part of a collaborative project, I worked on data quality, leakage safe feature engineering, machine learning models, and the dynamic allocation layer. My main modeling contributions predict task type, quantity or batch size, and microtask price to support task-allocation decisions on the Leyu platform.
