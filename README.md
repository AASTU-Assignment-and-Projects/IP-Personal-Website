# Personal Website — Mahider Feleke

## About the Project

This project is a personal website developed as part of an **Internet Programming** course assignment. 


## Pages and Features

The website consists of six HTML pages:

- **Home (`home.html`)** — Introduces me, my technical interests, and my goals.
- **About Me (`about.html`)** — Describes my background, educational journey, interests, and ambitions.
- **Skills & Education (`skills.html`)** — Presents my education, technical skills, and learning goals.
- **Projects & Achievements (`projects.html`)** — Highlights my projects in assistive technology, machine learning, and natural language processing.
- **Media & Interests (`midea.html`)** — Includes audio and video players, technical interests, and learning resources.
- **Contact Me (`contact.html`)** — Provides contact information and a form interface for sending messages.
